Release Cycle

Archcraft follows a rolling-release model. Update an existing installation with sudo pacman -Syyu.

New installation images are scheduled for April, August, and December. Significant bugs or upstream issues may require an additional release.

Archcraft is an independent project maintained by Aditya Shakya. GitHub sponsorships, Ko-fi contributions, and PayPal tips help fund development and maintenance.
